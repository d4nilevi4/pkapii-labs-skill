# pkapii-labs: скилл-помощник для лабораторных по Docker и Kubernetes

Скилл для [Claude Code](https://claude.com/claude-code). Помогает студенту, который делает практические по курсу «Программно-конфигурируемая архитектура приложений и инфраструктуры» (Docker, Docker Compose, Kubernetes через kind) в виртуальной машине на Mac. Это не готовые работы, а заметки о том, как настроить окружение, что ломается и как это чинить, плюс способ собирать настоящие доказательства (логи и скриншоты).

## Важно: прочитайте до использования

1. **Всё проверялось на Mac с чипом Apple (M-серия), в VirtualBox 7.2.x, с гостевой Ubuntu 22.04 для ARM64.** На Intel-Mac, Windows и Linux команды и обходы будут другими. Часть заметок про ARM и VirtualBox там не применима.
2. **Отчёты, сделанные в том опыте, были оформлены не по ГОСТ, и в таком виде их не примут.** Скилл ничего не оформляет: в нём нет шаблонов отчёта, разметки и правил вёрстки. Требования к оформлению берите у своей кафедры и проверяйте результат сами.
3. **В репозитории нет заданий.** Методички и вопросы защищены авторским правом. Скачайте их сами и положите в папку, где открыт Claude Code. Скилл читает файлы оттуда. Файлы заданий в `.gitignore`, чтобы их случайно не закоммитить.
4. **Скилл не выполняет работу за вас.** Он объясняет шаги, подсказывает типичные ошибки и проверяет, что у вас есть настоящие доказательства. Выводы, тексты и ответы на контрольные вопросы ваши. Узнайте правила вашего вуза про использование ИИ и следуйте им.
5. **Никаких гарантий.** Лицензия MIT, код и заметки предоставляются «как есть». Репозиторий не связан с университетом и не одобрен кафедрой. Автор не отвечает за оценки, потерянные данные и повреждённые виртуальные машины.

## Что умеет

- Подготовка ARM-виртуальной машины в VirtualBox на Apple Silicon: образ, создание, автоустановка, сеть, SSH, проброс портов, удаление. Включая обходы известных зависаний.
- Заметки по Docker и Compose: установка на ARM, тома PostgreSQL, сети, healthcheck, 502 у прокси.
- Заметки по Kubernetes и kind: бинарники для arm64, проброс NodePort на Mac, типичные ошибки `kubectl`, метод диагностики сломанного приложения.
- Сбор доказательств: скрипты записывают настоящий вывод команд и рисуют из него скриншот терминала. В отчёте нужно честно писать, что картинки нарисованы из транскрипта, а не сняты с экрана.
- Привычки проверки: сверка пунктов задания с логами, поиск одинаковых картинок, журнал проблем.

## Как поставить

Репозиторий пока приватный. Для установки нужен доступ к нему и авторизованный `git` или `gh`.

**Способ 1: попросить Claude.** Скопируйте ссылку на репозиторий и напишите Claude Code: «Установи скилл из этой ссылки: `<ссылка>`». Он скопирует папку скилла к вам.

**Способ 2: как плагин.**

```bash
claude plugin marketplace add <владелец>/pkapii-labs-skill
claude plugin install pkapii-labs@pkapii-labs-skill
```

**Способ 3: вручную.** Скопируйте папку `plugins/pkapii-labs/skills/lab-helper` в `~/.claude/skills/` (тогда скилл называется `lab-helper`).

## Как использовать

1. Создайте папку для работы и положите в неё свои файлы с заданиями (docx, pdf).
2. Откройте Claude Code в этой папке.
3. Напишите, например: «Помоги с практической по Kubernetes, задание в этой папке». Скилл подключится сам по описанию, либо вызовите его явно (`/pkapii-labs:lab-helper` для плагина).
4. Перед работой Claude напомнит про ограничения из раздела «Важно».

## Структура

```
.claude-plugin/marketplace.json            описание для установки
plugins/pkapii-labs/
  .claude-plugin/plugin.json
  skills/lab-helper/
    SKILL.md                               правила и порядок работы (на английском, чтобы тратить меньше токенов)
    references/vm-apple-silicon.md         ВМ на Apple Silicon
    references/docker-notes.md             Docker и Compose
    references/kubernetes-notes.md         Kubernetes и kind
    references/evidence.md                 настоящие логи и скриншоты
    scripts/vmrun.py, termshot.py          запись вывода и рендер терминала
```

Справочные файлы загружаются только когда нужны, поэтому скилл экономит токены.
